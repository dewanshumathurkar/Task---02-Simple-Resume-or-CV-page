# 📄 Simple Resume / CV Page

A clean, responsive, and professional Resume/CV webpage built using **HTML**, **CSS**, and **JavaScript**. This project was created as **Task 2** for the **SpireX Foundation Internship**.

## 📌 Features

- Responsive Resume Layout
- Professional Profile Section
- About Me
- Education Details
- Technical Skills
- Projects
- Contact Information
- Clean & Modern UI
- Mobile Friendly Design

## 🛠️ Technologies Used

- HTML
- CSS

## 📂 Project Structure

```
Resume-CV/
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click **index.html** or open it in your browser.
